What is the leakage current for an I/O pin? What is a leakage current?

(R8)

I/O pin leakage current: ±1 µA (max, at Vcc=5.5V)
Leakage current is the small amount of current that flows through a pin even when it is configured as an input (high-impedance state). It is caused by imperfections in the CMOS transistor gates and protection diodes. In practical terms, it represents unwanted current that "leaks" through the pin when it should ideally draw no current. This is important in low-power designs and when using high-impedance inputs, as leakage can affect voltage readings or increase power consumption.
